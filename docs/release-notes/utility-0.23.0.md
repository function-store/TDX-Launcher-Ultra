Collect, the media browser, autosave and phone multi-touch have left the
companion. They are FNSTools packages now: FNS_Collect, FNS_MediaBrowser,
FNS_Autosave (free) and FNS_Remote. Install them from the launcher's
FNSTools tab — each is a complete TouchDesigner tool that also works with
the launcher closed.

If you used any of those four, install the matching package after
updating, or they will simply be missing.

The companion keeps save, snapshot, record, asset re-rooting, window and
display control, the heartbeat watchdog and the performance readout.

The companion now carries FunctionStore's FNS_CommandRegistry (0.1.2, the
same artifact the FNSTools store installs) with TouchDesigner's built-in
commands inside it. Quick Launch lists them for any session running this
companion, and a project that also has the store package loaded resolves
both to one registry, so nothing is listed twice.
