Find a project without switching windows

Press the global hotkey — TD fullscreen included — and a small search box appears over whatever you're doing. Type a few letters, hit Enter: projects launch with the right build, running sessions focus, components place into the live session — or drag the row straight into a TouchDesigner network.

  • >verb-first commands per session — Focus, Save, Thumbnail, Preview video, Relaunch, Kill. Destructive ones arm on the first Enter and fire on the second, never on one keypress.
  • ?tool commands — actions the components inside a running project publish for themselves. Type the arguments inline: ? rec 2 and it's already recording.
  • =components only — your whole .tox library in one list.
  • /browse a palette folder, Toolbox category or your Patreon cache.
  • #filter by project tag — running sessions keep their tags, so a live show still surfaces.

Press Alt+↑ to recall a previous query.

Quick launch

A hotkey palette over everything — TD fullscreen included. Try it in the browser demo →

Summon anywhereThe main global hotkey raises the launcher window from anywhere; a second opens this small search box over whatever you're doing — type a few letters, hit Enter. A third raises the main window on the Palette tab; bind whichever combos you want, each on or off on its own.
Everything in one listProjects launch with the right build, running sessions focus, palette / Toolbox / Patreon components place into the live session, templates start new projects.
Commands> shows verb-first commands per session — Focus, Save, Thumbnail, Preview video, Relaunch, Kill, plus a new project from your default template. Destructive ones always ask for a second Enter.
Tool commandsComponents in a running project publish their own actions — ? lists them. Arguments render as chips and can be typed inline (? rec 2) or filled through a short prompt. Same command in several sessions? One row with a count, run against the session you were just in.
Query historyExecuted queries are remembered and cycle with Alt+↑ / Alt+↓, shell style — the thing you run before every show is two keystrokes away.

Phone Remote

Access running sessions from a phone on the same Wi-Fi. Try it in the browser demo →

One-tap pairingTap 📱, scan a QR, done — LAN access flips on and the remote opens on your phone (same Wi-Fi). Add it to the home screen; the pairing survives restarts.
Sessions as tabsEvery session — live or ended — is a tab: facts, heartbeat status, live perf readout, and Focus / Relaunch / Kill / Dismiss. Ended sessions relaunch with one tap.
Hold-to-confirmKill and Relaunch arm on press-and-hold with a filling bar and a haptic buzz — release early to cancel. Nothing destructive fires from a stray tap.
Straight into a session SoonA session running FNS_Remote gets an Open remote button on its tab: one tap and you are on that session's own page, served by TouchDesigner itself. Exposed parameters, the touch pad and save live there — so they keep working with the launcher closed.
Multi-touch surface SoonEvery finger as CHOP channels — x, y, force and active per slot, plus touch count and a connected-phone table — comes from FNS_Remote, which serves the phone from inside TouchDesigner. Several phones at once, and it runs with the launcher closed.
Client link SoonHand a client or operator the reduced page: only the controls you exposed — no session actions, no launching, no browsing. Enforced by the server, not hidden in the page. It is FNS_Remote's own link, and the fleet page hands it out per session.
Yours to runStart, stop, change the port (rebinds live), or regenerate the pairing code to cut off every shared link — all from Settings.

Running sessions

Inspect and control running TouchDesigner processes.

Session discoveryFinds every running TD process — including projects opened outside the launcher. Shows version, PID, uptime.
Session controlFocus the TD window, reveal the .toe, relaunch with a different version, or kill the process.
Status at a glanceA dot on every session: running, not responding (its companion stopped pulsing, so TD is frozen or busy), or ended. Ended sessions wait below an Ended divider and relaunch in one click.

Displays & GPUMulti-GPU machines: bind a project's TD process to one card at launch, and place its windows on the right displays through the companion. Both saved with the project.
Tray & loginClose-to-tray, quit-after-launch, start at login (minimized to the tray) — all Settings toggles.

Companion actions

What the companion TOX unlocks on a selected running session — plus whatever your installed FNSTools packages add to it.

Save, thumbnail, preview videoSave the .toe in place; capture a thumbnail or a preview clip (up to 30s) — the gallery picks them up automatically.
Autosave, via FNS_AutosaveTouchDesigner has none — the free FNSTools package FNS_Autosave adds one. Arm a timer inside the session, pick whether a save follows your increment/backup preferences or overwrites the open .toe, and skip saves when nothing changed or while you're in Perform Mode. Install it and it appears in the session view; it also runs with the launcher closed.
Collect, via FNS_Collect SoonScan for external media refs, copy them into the project, relink relative — dry-run checklist first, per-file opt-out, expression refs frozen to constant paths (or not, your call). An FNSTools package: install FNS_Collect and it appears in the session view. Works standalone inside TD, no launcher needed.
Media browser, via FNS_MediaBrowser SoonEvery movie, image, audio and geometry file the running project references — live preview, file facts (resolution, duration, fps, audio), Replace on any reference, Locate missing to batch-relink a moved folder, an Unused scan for dead weight, and timeline sync to a clip. An FNSTools package (FNS_MediaBrowser) with its own panel inside TD.
Load componentsSend a .tox into the network editor — from a local file, any URL, a GitHub release, or a package index.
Python envPackage installs go into the project's .venv, with uv when it's on the machine and the env's own pip otherwise; Set up Python env creates one via TDPyEnvManager in one click.
In-place utility updatesWhen a session runs an older companion, one click updates it live — parameter values survive the reload.
Embody / Envoy awareProjects built with the optional Embody/Envoy toolkit get an Envoy panel — bridge status, .mcp.json, port — and a last-resort transport for companion actions. Never required.

FNSTools

The FNSTools toolkit, browsable and installable without leaving the launcher — and where the launcher’s optional capabilities come from. Its Plus packages come with a Patreon membership. About the toolkit →

Launcher capabilitiesSome packages announce their commands to the running session, and the launcher renders them right in the Sessions view and its context menu — FNS_Autosave (free) brings autosave today; FNS_Collect, FNS_MediaBrowser and FNS_Remote — collect, the media browser and phone control — are coming soon. Each is a complete TouchDesigner tool in its own right: it works with the launcher closed, and lights up the session view when both are installed.
The storeThe current release by category, with descriptions, versions and docs links. What a session already has is pre-checked, with installed and 1.1.0 → 1.2.0 badges.
Install without TouchDesignerTick tools and stock them locally — verified downloads, no session needed. Or install straight into a running project over the companion bus, bootstrap included if the project has no toolkit yet.
The selection is the tool setInstalling makes the project match what you ticked, so unticking removes. The confirm step lists the adds and the removals before anything happens.
Global configuratorEvery tool's settings, edited from the launcher — with real menus, ranges and validation when a session is live, or straight into the config file when nothing is running.
Palette shelfEvery package also appears as a standalone component beside the Toolbox — drag one into a network, or place it into a session.

Command favouritesPin commands from the quick-launch, Settings, or the Commands tab; favourites sort first everywhere and travel with settings export/import.

Git & backup

Side panels for keeping projects safe — versioned or copied.

Git panelChanges and history, diffs, stage/commit, branch, pull/push — with your installed Git's credentials, or an optional GitHub token in Settings. Creating a repo seeds a TouchDesigner .gitignore, so Backup/, increments and crash autosaves stay out of the first commit.
Backup panelProject folder ↔ USB or synced folder; include/exclude globs and a max file size; backup, restore, sync — no deletes, ever.
Direct cloudConnect Google Drive, Dropbox, OneDrive, or Box: a one-time rclone download, sign in via your browser, then it's a backup destination.
